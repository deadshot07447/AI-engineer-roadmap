# AI Engineer Learning

A structured repository to document my journey toward becoming an AI Engineer.

## Purpose

The purpose of this repository is to track and document my learning progress across key disciplines in artificial intelligence and machine learning engineering. It serves as a centralized, long-term workspace containing:

- **Notes**: Theoretical concepts, architecture summaries, and key takeaways.
- **Exercises**: Focused coding problems, algorithmic implementations, and targeted practice.
- **Projects**: End-to-end, modular applications demonstrating practical implementation.
- **Experiments**: Quick prototypes, exploratory Jupyter notebooks, and scratch scripts.

## Multi-Machine Workflow

This repository is designed to be used across multiple development machines (e.g., MacBook and office laptop), with **GitHub** serving as the single source of truth.

To ensure seamless synchronization:
- Machine-specific dependencies, virtual environments, and local credentials are kept out of version control via `.gitignore`.
- Heavy model artifacts, weights, checkpoints, and large local datasets should not be committed directly to GitHub.
